# 수원·성남·안양·과천 주정차 단속 지도

수원·성남·안양시가 공개한 주정차 단속 기록으로 **어디서 단속이 자주 일어나는지** 보여 주는 지도예요. 과천은 시민 신고 기록만 있어서 참고용 층으로 따로 보여 줘요.

👉 **[지도 보기](https://victor-jo.github.io/suwon-parking-risk/)**

- 실시간 정보가 아니에요. 수원은 2022-01 ~ 2023-10 기록 약 79만 건, 성남은 2025년 기록 약 34만 건, 안양은 2025-01 ~ 10 기록 약 7만 7천 건, 과천은 2024년 신고 3,738건으로 만들었어요.
- 점을 누르면 "단속 있던 날 10일 중 N일"이 보여요. 수원 점에는 요일·시간표(참고용)와 2025년 9월에도 근처에서 신고가 있었는지가, 안양 점에는 2026년 8월에도 같은 100m 칸에서 위반이 있었는지가 더 보여요. 성남·안양 기록에는 시각이 없어서 시간표가 없어요.
- 고정 CCTV 지점에는 "신고가 없어도 카메라가 자동으로 단속해요"라는 경고가 떠요.

## 왜 만들었나

빈 주차 자리를 알려 주는 서비스는 이미 많아요. 그런데 "여기 잠깐 세우면 단속될까?"를 미리 알려 주는 지도는 찾지 못했어요.
두 시의 단속 기록에는 좌표가 없고 장소가 `인계동 ○○ 앞`(수원), `황새울로342번길 서현역 부근`(성남)처럼 글자로만 적혀 있어요. 이 프로젝트는 그 글자를 좌표로 바꾸고, 지점별로 단속이 얼마나 자주 있었는지 계산해요.

## 지도 읽는 법

| 표시 | 뜻 |
|---|---|
| 🔵 파란 원 | 고정 CCTV가 주로 단속한 곳 |
| 🟠 주황 원 | 순찰차·신고로 자주 걸린 곳 |
| 🟣 보라 원 | 과천: 시민 신고로 과태료가 붙은 곳 (신고 기록만, "신고 있던 날" 비율) |
| 원 크기 | 단속이 있던 날의 비율 (클수록 자주) |
| 점선 원 | 위치가 대략인 곳 (도로·동 단위). 기본으로 꺼져 있어요 |

**알아 둘 점**

- "어디"는 오래가지만 "몇 시"는 해마다 바뀌어요. 다른 해 기록으로 확인해 보니, 수원 옛 단속 지점은 2025년에도 500m 옆 자리보다 약 4배 자주 신고됐어요. 안양 2025년 지점도 2026년 8월에 59%가 같은 100m 칸에서 다시 걸렸어요(500m 옆 자리는 23%). 반면 정확한 요일·시간 칸은 많이 바뀌었어요. 그래서 요일·시간표는 참고용으로만 보여 줘요.
- 지도에 없다고 안전한 곳은 아니에요. 도시마다 자주 나온 장소 3,000곳만 좌표로 바꿨어요(수원 기록의 약 89%, 성남 약 88%, 안양 약 97%).
- 안양 2026년 8월 격자 건수는 신고·현장단속만 센 것이고(CCTV 없음), 원본 건수가 거의 다 3의 배수라 정확한 건수보다는 "많다·적다"로 보세요.
- 도시마다 기간이 달라요. 원 크기는 각 도시 자기 기간 안에서 "단속(과천은 신고) 있던 날 비율"이에요.
- 과천 보라 원은 CCTV·순찰 단속을 뺀 시민 신고만이라, 보라 원이 없는 곳도 단속될 수 있어요.
- 위치 정확도는 장소마다 달라요. CCTV 좌표나 주소로 찾은 곳은 정확해요. 수원에서 장소 이름으로 찾은 곳은 CCTV 실제 좌표와 비교했을 때 보통 74m(중간값) 정도 차이 났어요. 성남은 비교할 정답 좌표가 없어서 표본을 눈으로만 확인했어요.
- 팝업 제목은 카카오가 찾은 장소 이름이라, 가끔 바로 옆 가게 이름으로 보여요(예: "수내역 부근" → "수내역상품권"). 원래 기록상 이름도 팝업에 같이 나와요.

**새 데이터는 언제 나오나** (2026-11 기준)

- 성남 단속 위치는 해마다 갱신돼요. 다음 등록 예정일은 2027-02-05라서, 2026년 치가 나오면 같은 명령으로 다시 만들 수 있어요.
- 안양 단속 위치는 해마다 갱신되고 다음 등록 예정일은 2026-12-04예요. 안양 시청 [OpenAPI](https://www.data.go.kr/data/15126230/openapi.do)는 "실시간"으로 적혀 있지만 이 파일과 같은 내용이에요.
- 과천 신고 데이터는 1회성이라 다음 공개 예정이 없어요.
- 수원의 장소별 기록은 2023년에 한 번 공개된 뒤로 새로 나오지 않았어요. 2026-04에 나온 [수원시 주정차단속현황 (15063802)](https://www.data.go.kr/data/15063802/fileData.do)은 2025년 치인데, 구·방법·날짜별 건수만 있고 장소가 없어서 지도에는 못 써요.

장소 글자를 좌표로 바꿀 때는 [카카오 로컬 API](https://developers.kakao.com/docs/latest/ko/local/dev-guide)를 써요. 지도 배경은 [OpenStreetMap](https://www.openstreetmap.org/copyright)이에요.

## 직접 실행하기

**준비물**

- Python 3.12 이상과 [uv](https://docs.astral.sh/uv/)
- 카카오 REST API 키 (좌표 변환할 때만 필요해요)

```bash
uv sync
echo "KAKAO_REST_API_KEY=발급받은_키" > .env   # .env는 git에 올라가지 않아요
```

**지도 만들기**

```bash
uv run suwon-parking fetch                    # 데이터 8종을 data/raw/에 내려받기
uv run suwon-parking geocode                  # 수원 자주 나온 장소 3,000곳을 좌표로 (카카오 API, 캐시됨)
uv run suwon-parking geocode --fines          # 2025-09 신고 장소를 좌표로
uv run suwon-parking geocode --city seongnam  # 성남 자주 나온 장소 3,000곳을 좌표로
uv run suwon-parking geocode --city anyang    # 안양 자주 나온 장소 3,000곳을 좌표로
uv run suwon-parking geocode --city gwacheon  # 과천 신고 장소 611곳 전부를 좌표로
uv run suwon-parking map                      # 네 도시를 합친 data/map.html 만들기
open data/map.html                            # 서버 없이 바로 열려요
```

좌표 변환 결과는 `data/geocode_cache.jsonl`(다른 도시는 `data/geocode_cache_<도시>.jsonl`)에 쌓여서, 다시 실행해도 API를 또 부르지 않아요.

**그 밖의 명령** (수원 데이터만 써요)

| 명령 | 하는 일 |
|---|---|
| `profile` | 건수, 기간, 장소 분포, 시간대별 건수 출력 |
| `validate` | 카카오 좌표를 CCTV 실제 좌표와 비교해 채점 |
| `aggregate` | 지점 × 요일 × 시간별 단속 비율을 `data/cells.csv`로 저장 |
| `freshness` | 고색동 구역에서 2022~23년 패턴이 2021년, 2024~25년에도 맞는지 확인 |
| `recent` | 수원 전체에서 옛 단속 지점이 2025-09에도 신고됐는지 확인 |

**테스트**

```bash
uv run pytest
```

## 폴더 구조

```text
src/suwon_parking/
  fetch.py             공공데이터포털에서 파일 내려받기
  records.py           CSV 읽기 (수원·안양·과천 cp949, 성남 UTF-8, 깨진 시각 표기 처리)
  geocode.py           장소 글자 → 좌표 (도시별 카카오 검색 + 캐시)
  cctv.py              수원 CCTV 목록과 장소 이름 맞추기
  aggregate.py         지점 × 요일 × 시간 집계
  points.py            지도 점 요약, 2025 신고 붙이기
  grid.py              안양 100m 격자(zip 속 dbf) 읽기, 지점에 칸 건수 붙이기
  freshness.py         다른 기간에도 패턴이 맞는지 비교
  mapview.py           지도 HTML 만들기
  map_template.html    지도 페이지 틀 (Leaflet)
  cli.py               suwon-parking 명령
tests/                 pytest 테스트
data/                  내려받은 원본, 캐시, 결과물 (git에 안 올림)
context-notes.md       작업하며 내린 결정과 그 이유
```

## 지도 다시 배포하기

지도는 `gh-pages` 브랜치의 `index.html` 한 파일이에요.

```bash
uv run suwon-parking map
git worktree add /tmp/pages gh-pages
cp data/map.html /tmp/pages/index.html
(cd /tmp/pages && git commit -am "지도 갱신" && git push)
git worktree remove /tmp/pages
```
